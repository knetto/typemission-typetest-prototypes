⚙️ WordPress Implementatie Gids

Volg deze stappen om de Kraak de Kluis op je WordPress website te zetten:

  1. Upload de map: Upload de volledige map kluis-iframe via FTP of File Manager naar de server van je website (bijv. in /public_html/typetests/kluis-iframe/).
  2. WordPress Blok toevoegen: Bewerk je pagina of bericht in WordPress en voeg een Custom HTML (Aangepaste HTML) blok toe.
  3. Code plakken: Kopieer en plak de code hiernaast in dat blok.
  4. URL aanpassen: Vervang in de code de link src door de echte URL van je website (bijvoorbeeld https://jouwwebsite.nl/typetests/kluis-iframe/).
Tip: Omdat we de website headers, menu's en banners hebben weggelaten, laadt de typetest nu supersnel en past deze perfect binnen de lay-out van je WordPress-pagina!

📄 WordPress HTML Code

Kopieer deze code naar je WordPress Custom HTML blok. Pas de src link aan naar jouw online pad:

<style> @media (max-width: 768px) { #typetest-iframe { display: none !important; } } </style> <iframe id="typetest-iframe" src="./iframe version/kluis-iframe/index.html" width="100%" height="700px" style="border: none; overflow: hidden; display: block; background: transparent;" allowfullscreen> </iframe> <script> window.addEventListener('message', function(event) { if (event.data && event.data.type === 'resize-iframe') { const iframe = document.getElementById('typetest-iframe'); if (iframe) { const nextHeight = event.data.height + 'px'; if (iframe.style.height !== nextHeight) { iframe.style.height = nextHeight; } } } }); </script>

Opmerking: De hoogte wordt nu volautomatisch en dynamisch aangepast aan de hand van de inhoud (bijvoorbeeld als de resultaten worden getoond). Geen dubbele scrollbalken meer!
